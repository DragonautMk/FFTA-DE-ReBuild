# FFTA DE-ReBuild 1.1.0 — release notes

This release is primarily a development and research update. Most of the work
since 1.0.0 concerns understanding and reimplementing game code and data, and
improving the tools used to inspect and debug it. For most players, the basic
experience will be much the same; this is not a major gameplay update.

## What's changed

- Expanded the analysis and native handling of European ROM data, including
  graphics, animation and game context data. Coverage is still incomplete and
  many observations are limited to specific scenes or configurations.
- Extended developer tools for debugging, recording and replaying sessions,
  inspecting game data and managing diagnostics. These tools are intended for
  investigation and do not imply complete game coverage.
- Improved cheat browsing and configuration, including favorites and parameter
  selection. Individual cheats and character values have different validation
  and provenance; consult the in-app guidance and [cheat guide](../cheats.md).
- Improved build and validation infrastructure for portable desktop packages
  and the separately maintained Android preview.

Existing compatibility limitations still apply. An original supported game ROM
is required and is not included. Android remains a separate source tree and its
APK is a debug-signed preview, not a promise of identical desktop features.

## Release status

Release candidate packages have passed the Linux and Windows container test
gates and the Android build and unit tests. Windows was tested under Wine;
native Windows and physical Android device testing are still outstanding. The
Android APK uses a debug signing key. The release has not been published.
See the [portable build guide](../portable.md) and [Android build guide](../android_docker.md).

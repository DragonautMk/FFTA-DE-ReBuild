# FFTA DE-ReBuild 1.1.2

This update fixes the Android battle laws screen and improves release builds
for Android, Linux and Windows. Android feature parity remains in progress.

## Android

- Display the complete, centered battle laws and HELP panel, including the
  observed taller multirow layout.
- Confirm before exiting a game. A confirmed exit saves cartridge progress and
  closes the app; a save error keeps the menu open.
- Update the Android build tools while retaining the Docker SDK and compiler
  caches. The Android preview keeps the previous signing certificate and can
  be installed over it without removing app data.

## Desktop

- Make a debug recipe's in-flight cancellation wait briefly for an existing
  transition writer, so a concurrent valid cancellation can be acknowledged.
  Malformed cancellation markers are rejected.

## Downloads

- **Windows x86-64**: `FFTARecomp-windows-portable.zip`
- **Linux x86-64**: `FFTARecomp-linux-portable.tar.gz`
- **Android ARM64**: `FFTARecomp-android-arm64-preview.apk`

An original supported game ROM is required. Provide your own BIOS where the
chosen configuration requires one. Game files and saves are not included.

The Android APK is a debug-signed preview. Its app version is
`1.1.2-android-preview` and its version code is 27. The desktop packages retain
their existing internal Cargo version numbers.

Android still lacks some desktop menu, video and debug features, including
state-slot previews and temporal response. Other multirow laws layouts and USA
ROMs remain unverified, as does the Cancel action in the exit dialog. State
transfer, undo and backup flows have synthetic coverage; real-game transfer,
undo and backup restore on a phone are not fully verified. Android uses one
shared primary cartridge save when switching ROMs.

The Linux Docker build passed its full test gate and the packaged command-line
executable started successfully. The Windows Docker build passed its tests
under Wine; native Windows was not tested. The Android Docker build passed its
29 Kotlin unit tests. This APK was installed on a moto g34 5G with cartridge
saves and snapshots unchanged. On the previous build, the user confirmed the
corrected laws panel and direct app exit.

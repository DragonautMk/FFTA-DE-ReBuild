    Progression and pricing records
    
  
    These European tables retain physical IDs and stored values. They do not
  establish a character's live state, reward availability, skill names, item
  links or the result of running the original game code.
    
  
    Progression deltas and discount
    
    Eight stored deltas feed corresponding progress slots; the discount byte
    is used by a separate price reader. The final byte remains unclassified.
    
    
    
  
    
  
    Progression requirements
    
    The original reader checks all eight minima for each unreceived physical
    row. The returned halfword and output byte are shown without inferring an
    item or reward identity; a zero return can still belong to a matching row.
    
    
    
  
    
  
    Progression selection conditions
    
    All three minima must pass. If any of the eight slot minima is nonzero,
    at least one active minimum must pass; a nonzero flag is checked separately.
    The first eligible physical row is significant. A row without conditions
    stores zero; an exhausted table leaves the previous value unchanged.
    
    
    
  
    
  
    Trade price parameters
    
    Count zero reads byte 0x41, the high byte of the markup field. Counts
    1–30 use the following discount bytes. The preceding 64 bytes are preserved
    as unclassified data; live flags and other price inputs are not simulated.

    Song track sequences
    
  
    Explore one track or play the extracted tracks together. Known PCM and
  CGB wave instruments can use extracted samples; CGB square voices use their
  stored duty cycles. Fixed-rate PCM uses an assumed mixer rate that can be
  changed below; the default was observed in one European checkpoint. Other
  voices fall back to sine waves. Tempo commands from all tracks can guide the
  timing even when listening to one track. Frame timing models the driver's
  nominal frame cadence and starts at one tick per frame; the continuous
  estimate uses the manual rate before the first tempo command. Disabling song
  tempo uses the manual rate throughout. The live tempo multiplier, mixing,
  bends, envelopes and effects remain approximate. The trace has safety limits.

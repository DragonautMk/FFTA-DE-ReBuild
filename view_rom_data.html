    Background tile sheets
    
  
    Decoded words are shown as 4-bit, 8×8 tiles using a selected base palette
  or grayscale indices. This is a tile sheet, not an assembled scene. Any
  destination prefix and live palette or animation changes are not included.
    
  
  
  
  
    
  

    

    
  
    Interface tile sheets
    
  
    Decoded UI banks are shown as 4-bit, 8×8 tiles. Some words may represent
  other data. Palette selection is manual and does not imply a verified pairing
  or an assembled screen.
    
  
  
  
    
  
  
  
  
  
    
  

    

    
  
    Object tile sheets
    
  
    Decoded object banks are shown as 4-bit, 8×8 tiles. Some words can hold
  other data. Palettes are chosen manually; neither their pairing nor a finished
  sprite or screen is inferred.
    
  
  
  
    
  
  
  
  
  
    
  

    

    
  
    Tilemap and rectangle explorer
    
  
    Choose extracted cells and optionally interpret them as 4-bit background
  tile entries. Graphics, tile placement and colors are selected manually;
  the preview does not establish the game's actual scene or palette pairing.
  You can apply one selected color bank to every cell, or use the stored
  palette IDs within the selected palette source.

    Song track sequences
    
  
    Explore one track or play the extracted tracks together. Known PCM and
  CGB wave instruments can use extracted samples; other voices fall back to
  sine waves. Tempo commands from all tracks can guide an estimated playback
  rate, even when listening to one track. The manual rate applies before the
  first tempo command or when the option is disabled. Driver timing, bends,
  envelopes and effects remain approximate. The trace has safety limits.
    
  
  
  
  
  
  
  
  
  
  
    Mute applies to CGB instruments identified from the extracted tone data,
  including sine fallbacks. Unidentified voices remain audible. The setting is
  retained between tracks and, when browser storage is available, on reload.

    Short texts
    
  
    Hidden controls leave a space between text. Normal font uses a visually
  matched European Latin subset; other glyphs retain their original image.
    
  
  
  
  
  
  
  
    
  
    

    

    
  
    Pointer text catalogs
    
  
    Browse extracted pointer tables by reader, language and entry. Control bytes
  are shown as stored; substitutions and formatting are not executed. Hidden
  controls leave a space. Normal font uses a visually matched European Latin
  subset; other glyphs retain their original image.
    
  
  
  
  
  
  
  
  
    
  
    

    

    
  
    Relative text archives
    
  
    Browse archive programs by reader and language. Commands and operands are
  labeled as stored; dynamic substitutions and formatting are not executed.
  Hidden commands leave a space. Normal font uses a visually matched European
  Latin subset; other glyphs retain their original image.
    
  
  
  
  
  
  
  
  
    
  
    

    

    
  
    Script text archives
    
  
    Select a physical bank and program. Commands and operands are shown as stored;
  dynamic names, choices and formatting are not executed. Hidden commands leave
  a space. Normal font uses a visually matched European Latin subset; other
  glyphs retain their original image.
    
  
  
  
  
  
  
  
  
    
  
    

    

    
  
    Font glyph atlas
    
  
    Browse the complete extracted 16×16 glyph slots. Grayscale represents
  stored pixel indices; the game's palette and Unicode mapping are not inferred.
  Width is the stored variable-width metric, independent of the full slot shown.
    
  
    
  
  
  
  
  
  
    
  
    

    

    
  
    Name-entry keyboard
    
  
    Explore the extracted keyboard pages and select cells to compose a local
  preview. Row widths and codes are stored data; this preview does not apply the
  game's name rules or translate glyphs to Unicode.

    Sprite tiles
    
  
    Grayscale represents palette indices. Tile sheets show source order.
    
  
  
  
  
  
  
  
    Select a sprite to preview its frames.
    
  
    Playback starts at the selected frame and continues to the end, or repeats
  when looping is enabled. Stored durations use the chosen preview rate; a zero
  duration is shown for one preview tick. This is not game timing.
    
  
    
  
  
    
  
  
  
  
    
  

    

    
  
    Actor, equipment and script sprite sequences
    
  
    Browse extracted battle, equipment and script sprite bindings and preview
  their stored frames. Script witnesses describe conditional source relationships,
  not guaranteed live actor behavior. Palette selection is manual. The preview uses a chosen
  tick rate; task commands, game timing, live palettes and composition of actor
  parts are not reproduced. Shared index roots are not sequence headers.
